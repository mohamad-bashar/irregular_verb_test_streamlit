# Irregular Verbs Quiz

This project is an interactive web application built using Python and Streamlit designed to help users practice and test their knowledge of English irregular verbs in a fun way.

## Features

*   Presents users with irregular verbs and asks for their past tense or past participle forms.
*   Provides immediate feedback on answers.
*   Keeps track of the user's score.
*   Includes a downloadable PDF list of irregular verbs for offline study.
*   User-friendly and engaging interface powered by Streamlit.

## Purpose

This app aims to make the often tedious task of learning irregular verbs more interactive and enjoyable.

## Live Application

You can access the live quiz here:
[https://irregular-verbs.streamlit.app](https://irregular-verbs.streamlit.app)

## Technologies Used

*   Python
*   Streamlit
*   Pandas (likely used for handling the verb list)

## How to Run Locally (Example)

1.  Clone the repository: `git clone https://github.com/mohamad-bashar/irregular_verb_test_streamlit.git`
2.  Navigate to the project directory: `cd irregular_verb_test_streamlit`
3.  Install dependencies: `pip install -r requirements.txt` (Assuming a requirements file exists)
4.  Run the Streamlit app: `streamlit run app.py` (Assuming the main script is app.py)
